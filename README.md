# UX Portfolio — GitHub Pages

A static, responsive UX portfolio with six projects, filters, and case-study overlays. No build tools or paid hosting required.

## Publish
1. Create a **public** GitHub repository named `yourusername.github.io` (replace `yourusername` with your actual GitHub username).
2. Upload **the contents** of this folder (not the folder itself) to the repository root.
3. In GitHub, go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Visit `https://yourusername.github.io` after GitHub finishes deploying.

## Customize before publishing
- Replace the generic portfolio branding, intro and About copy in `index.html` with your name and voice.
- Contact links and resume PDF are included. Update them if your details change.
- Edit `projects.js` to refine project copy, including your exact role and process.
- The original uploaded reports are included in `assets/` and linked from the project pages. Review them for personal details before making the repo public.
- Update the visual theme in `styles.css`.

## Notes
The six project pages are a polished first draft, not yet long-form case studies. Do not claim that recommendations were shipped or that conceptual prototypes were clinically validated. The website works without external libraries; Google Fonts are optional and fall back to system fonts.
